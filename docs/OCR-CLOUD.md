# OCR แบบเลือกโมเดลได้ (Typhoon OCR)

## ตั้งค่าครั้งเดียว (ผู้ดูแล)
1. สร้าง API key ที่ https://playground.opentyphoon.ai (เก็บเป็นความลับ — อย่าวางในแชท/โค้ด/GitHub)
2. Vercel → Project → Settings → Environment Variables → เพิ่ม `TYPHOON_API_KEY`
   (ไม่บังคับ: `SAND_TYPHOON_MODEL` ค่าเริ่มต้น `typhoon-ocr`) แล้ว **Redeploy**
3. ตรวจ: เปิด `https://โดเมนของคุณ/api/ocr` ต้องเห็น `{"cloud":true,...}` (ไม่แสดง key)
4. ผู้ใช้เลือกโมเดลที่ ตั้งค่า → การอ่านข้อความจากภาพสแกน

## โควตา
Typhoon OCR จำกัด 2 คำขอ/วินาที และ 20 คำขอ/นาที ต่อบัญชี — 1 หน้า = 1 คำขอ และทุกคนในหน่วยงานใช้โควตาร่วมกัน
โหมด "อัตโนมัติ" จึงเป็นค่าที่แนะนำเมื่อเปิดใช้ Typhoon (เต็มแล้วอ่านในเครื่องต่อให้เอง)

## ความเป็นส่วนตัว
เมื่อใช้ Typhoon ภาพหน้าเอกสารถูกส่งไปที่ Typhoon (SCB 10X) ผ่าน `/api/ocr` — ค่าเริ่มต้นจึงคือ "ในเครื่อง"
ควรตกลงนโยบายของหน่วยงานก่อนใช้กับหนังสือที่มีข้อมูลผู้ป่วยหรือชั้นความลับ
