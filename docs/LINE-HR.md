# แจ้งเตือน LINE ของระบบ HR + ลงลาจากมือถือ

ทำอะไรได้

| ฟีเจอร์ | วิธีทำงาน |
|---|---|
| **รายงานสัปดาห์หน้า** | ทุกวันศุกร์ (ปรับวัน/เวลาได้) ส่งว่าใครบันทึก ลา · ไปราชการ · อบรม · ประชุม ในสัปดาห์ถัดไป พร้อมวันหยุดราชการและวันที่ผู้ลาครบโควต้า |
| **สรุปวันลารายกลุ่มงาน** | วันทำการสุดท้ายของเดือน ส่งวันลาของบุคลากรแต่ละกลุ่มงาน (ป่วย/กิจ/พักผ่อน/เรียน) เฉพาะ แอดมิน + หัวหน้า |
| **ริชเมนู / พิมพ์คำสั่ง** | `สัปดาห์นี้ใครลา` · `สัปดาห์หน้าใครลา` · `วันนี้ใครลา` · `สรุปลาเดือนนี้` (ตอบด้วย reply token = **ไม่เสียโควต้าข้อความ**) |
| **ลงลาจากมือถือ** | `#/leave` — เลือกชื่อ → ประเภท → วัน → บันทึก ลงชีตเดียวกับหน้า HR ทันที |

```
LINE ──► Vercel /api/line (ตรวจ X-Line-Signature) ──► Apps Script action "line" (HrLine.gs) ──► ตอบกลับใน LINE
Apps Script (ตัวตั้งเวลา) ──► LINE push/multicast ──► ผู้รับตาม "บทบาท"
มือถือ #/leave ──► Apps Script action "hr" (op mobileBoot / saveData …) ──► ชีต HR_Control
```

> ทำไมต้องมี `/api/line` คั่นกลาง: Apps Script web app อ่าน header `X-Line-Signature` ไม่ได้ จึงแยกของจริงออกจากของปลอมไม่ได้ ตัวกลางนี้ตรวจลายเซ็นก่อนแล้วจึงส่งต่อ

## 1. ฝั่ง Google Apps Script (backend)

1. เพิ่มไฟล์ **`HrLine.gs`** (ไฟล์ใหม่) ในโปรเจกต์เดิม แล้วนำ **`Hr.gs`** และ **`Code.gs`** ใหม่ไปวางทับ
2. Project Settings ▸ **Script properties**

| Property | จำเป็น | ความหมาย |
|---|---|---|
| `LINE_CHANNEL_ACCESS_TOKEN` | ✔ | Channel access token (long-lived) ของ LINE OA |
| `EDGE_SECRET` | ✔ (มีอยู่แล้ว) | ค่าเดียวกับ `SAND_EDGE_SECRET` ใน Vercel |
| `LINE_CHANNEL_ACCESS_TOKEN_BACKUP` | – | บัญชี OA สำรอง (สลับได้ในหน้า #/hr-line) |
| `HR_LINE_GROUP_IDS` | – | รหัสกลุ่ม LINE ที่รับรายงาน/ถามได้ (คั่นด้วย , ) — พิมพ์ `รหัสกลุ่ม` ในกลุ่มเพื่อให้บอทตอบรหัส |
| `HR_LINE_QUERY_SCOPE` | – | `leave` = คำสั่งพิมพ์/ริชเมนูแสดงเฉพาะการลา (ค่าเริ่มต้น `all` = ลา+ราชการ+อบรม+ประชุม) |
| `HR_LINE_APP_URL` | – | ลิงก์ท้ายรายงาน แนะนำ `https://โดเมนของคุณ/?openExternalBrowser=1#/leave` |
| `HR_LINE_LIMIT_PER_MIN` | – | จำนวนคำขอ webhook ต่อนาที (ค่าเริ่มต้น 240) |

3. เลือกฟังก์ชัน **`hrLineSetup`** ▸ Run (1 ครั้ง) — สร้างแท็บ `LineUsers`, `LineReportSchedule` และตัวตั้งเวลา
4. **Deploy ▸ Manage deployments ▸ แก้ไข ▸ New version** (ต้อง deploy เวอร์ชันใหม่ ไม่เช่นนั้นเว็บยังเรียกโค้ดเก่า)
5. ทดสอบ: ฟังก์ชัน `hrLineTestAdmins` ส่งรายงานสัปดาห์หน้าให้เฉพาะบทบาท “แอดมิน”

## 2. ฝั่ง Vercel (GitHub)

คัดลอกไฟล์ตามพาธเดิม แล้ว commit → Vercel deploy อัตโนมัติ

Environment Variables (Settings ▸ Environment Variables) แล้ว **Redeploy**

| ตัวแปร | ค่า |
|---|---|
| `SAND_LINE_CHANNEL_SECRET` | **Channel secret** ของ LINE OA (ใหม่) |
| `SAND_GAS_URL`, `SAND_EDGE_SECRET` | ใช้อยู่แล้วกับ Telegram/QR |

## 3. LINE Developers / LINE Official Account Manager

1. LINE Developers ▸ Channel ▸ Messaging API ▸ **Webhook URL** = `https://โดเมนของคุณ/api/line` ▸ **Verify** (ต้องขึ้น Success) ▸ เปิด **Use webhook**
2. LINE OA Manager ▸ ตั้งค่าตอบกลับ: **ปิดข้อความตอบกลับอัตโนมัติ** (ไม่เช่นนั้นจะมีข้อความซ้อน)
3. สร้าง **ริชเมนู** (หน้าแชท ▸ ริชเมนู) — แนะนำ 3 ปุ่ม

| ปุ่ม | ชนิดการกระทำ | ค่า |
|---|---|---|
| สัปดาห์นี้ใครลา | **ข้อความ** | `สัปดาห์นี้ใครลา` |
| สัปดาห์หน้าใครลา | **ข้อความ** | `สัปดาห์หน้าใครลา` |
| ลงลา / ไปราชการ | **ลิงก์** | `https://โดเมนของคุณ/?openExternalBrowser=1#/leave` |

   > `?openExternalBrowser=1` ทำให้ LINE เปิดลิงก์ใน Safari/Chrome แทนเบราว์เซอร์ในแอป เพราะ Google ไม่อนุญาตให้ล็อกอินในเบราว์เซอร์ฝังของ LINE — ล็อกอินครั้งแรกครั้งเดียว หลังจากนั้นเซสชันถูกจำไว้ (ตาม `SESSION_TTL_MIN`) ปุ่มลงลาจึงเปิดเข้าหน้าบันทึกได้เลย  
   > ปุ่มแบบ “ข้อความ” ไม่ต้องล็อกอินเว็บเลย — ผลลัพธ์ตอบในแชท

4. ให้บุคลากรเพิ่ม OA เป็นเพื่อน → เปิด `#/hr-line` (แอดมิน) → **กำหนดบทบาท** ให้ทุกคนในรายชื่อ

## 4. บทบาท (แท็บ LineUsers หรือหน้า #/hr-line)

| บทบาท | ได้รับ | ถามได้ |
|---|---|---|
| แอดมิน | ทุกรายงาน | ทุกคำสั่ง |
| หัวหน้า | ทุกรายงานที่กำหนดผู้รับให้หัวหน้า (ค่าเริ่มต้น: ศุกร์ + สิ้นเดือน) | ทุกคำสั่ง รวมสรุปรายเดือน |
| บุคลากร | รายงานสัปดาห์หน้า | ใครลา (สัปดาห์นี้/หน้า/วันนี้) |
| *(ว่าง)* | **ไม่ได้อะไร** | **ถามไม่ได้** — บอทตอบให้รอแอดมินกำหนดบทบาท |
| กลุ่ม | กลุ่มที่อยู่ใน `HR_LINE_GROUP_IDS` | ตอบเฉพาะคำสั่งที่รู้จัก ไม่ตอบแชททั่วไป ไม่แสดงสรุปรายเดือนในกลุ่ม |

## 5. ลงลาจากมือถือ (`#/leave`)

- ใช้ได้จากเมนู “ลงลา (มือถือ)”, ไอคอนแอป (กดค้างที่ไอคอน SAND หลัง “เพิ่มไปยังหน้าจอโฮม”), หรือปุ่มริชเมนู
- ลิงก์ลัด: `#/leave` · `#/leave?tab=who` (ใครลา) · `#/leave?tab=who&week=next` (สัปดาห์หน้า) · `#/leave?tab=mine` (ของฉัน)
- ครึ่งวัน (เช้า/บ่าย) ใช้ได้กับ ลากิจ/ลาป่วย/ลาพักผ่อน · หลายวันติ๊ก “หลายวัน”
- กติกาเหมือนหน้า HR: ห้ามลาวันหยุดราชการ, โควต้าผู้ลาต่อกลุ่มงาน/วัน (เกินต้องใส่เหตุผล), เตือนวันทำการเหลือไม่ถึง 20 วัน, แก้/ลบได้เฉพาะรายการของตนเอง (หรือแอดมิน)

## 6. ความเป็นส่วนตัวและโควต้า

- รายงาน **ไม่แสดงหมายเหตุของการลา** (อาจมีชื่อโรค) แสดงเฉพาะประเภท วัน และสำหรับราชการ/อบรม/ประชุม แสดงสถานที่/ภารกิจ
- ก่อนส่งทุกครั้งระบบเช็กโควต้าข้อความของ OA ถ้าเดือนนี้ไม่พอ **จะไม่ส่ง** และแจ้งในหน้า #/hr-line — ส่งแบบ multicast (500 คน/ครั้ง) นับ 1 ข้อความต่อผู้รับ
- ข้อความเกิน 4,500 ตัวอักษรถูกแบ่งเป็นหลายข้อความ (สูงสุด 5)
- สรุปสิ้นเดือนส่งซ้ำไม่ได้ในเดือนเดียวกัน (ปุ่ม “ส่งทันที” ข้ามกฎนี้ได้เมื่อแอดมินสั่งเอง)

## 7. แก้ปัญหา

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| Verify ใน LINE Developers ไม่ผ่าน (401) | `SAND_LINE_CHANNEL_SECRET` ผิด หรือยังไม่ Redeploy หลังใส่ตัวแปร |
| กดริชเมนูแล้วเงียบ | ยังไม่ได้ deploy Apps Script เวอร์ชันใหม่ · `EDGE_SECRET` ไม่ตรงกับ `SAND_EDGE_SECRET` · คนนั้นยังไม่มีบทบาท |
| มีข้อความตอบซ้อน 2 ข้อความ | ยังไม่ได้ปิดข้อความตอบกลับอัตโนมัติใน OA Manager |
| รายงานศุกร์ไม่มา | หน้า #/hr-line ▸ ตัวตั้งเวลา = 0 → กดบันทึกตารางเวลา (สร้างตัวตั้งเวลาใหม่) · ไม่มีผู้รับตามบทบาท · โควต้าเดือนนี้หมด |
| เปิด #/leave ไม่ได้ “เปิดหน้าลงลาไม่ได้” | ยังไม่ได้เพิ่ม `HrLine.gs` / ยังไม่ Deploy เวอร์ชันใหม่ |
| ล็อกอิน Google ในแอป LINE ไม่ได้ | ใช้ลิงก์ที่มี `?openExternalBrowser=1` |
