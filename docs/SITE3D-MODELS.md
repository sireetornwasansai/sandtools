# โมเดล 3 มิติของแต่ละระบบ · ตัวเลขลอย · ป้ายฐาน · ตัวคน

หน้าแรก 3 มิติของ sandtools (site-sim.js) วาดด้วย canvas เอง ไม่ใช้ไลบรารีและไม่ใช้ไฟล์ glTF ดังนั้น "โมเดล" ของแต่ละระบบคือโค้ดวาดแบบ isometric
(ฟังก์ชัน `prop()` ใน site-sim.js) ระบบที่ยังไม่มีโค้ด ให้เตรียมโมเดลไว้ก่อน แล้วระบบจะเลือกโมเดลให้อัตโนมัติจากชื่อ/ที่อยู่เว็บ/แท็กของโครงการ

## โมเดลประจำระบบ

| ระบบ | ธีม | โมเดล | จับอัตโนมัติจาก |
|---|---|---|---|
| ระบบยานพาหนะ SAND | `ems` 🚑 | รถพยาบาล ไฟฉุกเฉินกะพริบเมื่อมีคนออนไลน์ (อยู่ตึกอุบัติเหตุ–ฉุกเฉิน) | ยานพาหนะ · รถ · sand · ems |
| HRD | `hrd` 🎓 | ห้องอบรม: กระดานขาว แท่นวิทยากร โต๊ะเรียน 2×3 | hrd · อบรม · บุคลากร |
| ยื่นจริยธรรมการวิจัยในมนุษย์ | `ec` 🔬 | ห้องวิจัย: โต๊ะแล็บ กล้องจุลทรรศน์ ขวดทดลอง โต๊ะเอกสาร + โล่จริยธรรม | จริยธรรม · วิจัย · ec · irb |
| วัคซีน | `vaccine` 💉 | ตู้เย็นวัคซีน เตียงตรวจ ถาดวัคซีน + พยาบาล (หมวกพยาบาล) | วัคซีน · vaccine · epi |
| **ติดตามประเมินผลงาน / ยื่น อวช.** *(ใหม่)* | `eval` 🏆 | ผนังความคืบหน้า 4 ขั้น + เครื่องหมายถูก → ถาดยื่นแฟ้ม → โต๊ะตรวจ + จอ → แท่นรับรางวัล 3 ขั้น + ถ้วย + ผู้ตรวจถือคลิปบอร์ด | อวช · ประเมินผลงาน · ติดตามผลงาน · ยื่นผลงาน · portfolio |

* บังคับธีมเองได้ด้วยแท็กในโครงการ: `theme:eval` `theme:ems` `theme:hrd` `theme:ec` `theme:vaccine` (ธีมอื่นดู README เดิม)
* ระบบ `eval` อยู่ปีก "พัฒนาคุณภาพ" ของตึกผู้ป่วยนอก (เปลี่ยนด้วยแท็ก `group:admin` หรือ `bld:er` ได้เหมือนเดิม)
* ที่ว่า "อวช." ในที่นี้ผมตีความเป็นปลายทางของการยื่นผลงานเพื่อรับการประเมิน ถ้าความหมายต่างไป แก้เฉพาะกฎคำค้นใน `RULES` (site-engine.js) หรือใช้แท็ก `theme:eval`
* เพิ่มระบบใหม่อีก: เพิ่มธีมใน `THEMES` + กฎใน `RULES` (site-engine.js) + `else if (th === '…')` ใน `prop()` (site-sim.js) + ใส่ธีมในปีกของ `HOSP_GROUPS`

## ตัวเลขลอย 3 มิติ (แทนตัวเลขบนแท็บสีขาว)

เหนือโมเดลแต่ละระบบมีตัวเลขการใช้งานลอยอยู่: ตัวเลขหนาแบบมีความหนา (หลายชั้น) มีเงาบนพื้นและเส้นประเชื่อมลงมาที่โมเดล ลอยขึ้นลงเบา ๆ และ **นับเลขขึ้นทีละน้อย** เมื่อค่าเปลี่ยน
ใต้ตัวเลขมีตัวอักษรเล็ก `ครั้ง` และ `● ออนไลน์ N` (เขียวกะพริบ) · ระบบที่ไม่มีข้อมูล/เงียบ/หยุดเก็บ แสดงเป็นคำสถานะแบบ 3 มิติสีเทา/แดงแทน
ใช้ครบทั้ง 3 มุมมอง: ผังแผนก · ภายในอาคาร (ห้องระบบ) · ภายในระบบ (ห้องหน้าเว็บ) · เปิด "ลดการเคลื่อนไหว" ในอุปกรณ์ → ไม่ลอย ไม่แกว่ง ไม่นับขึ้น

## ป้ายฐานโมเดล

ที่ฐานโมเดลมีป้ายสีเข้ม: บรรทัดบน **ชื่อระบบ** (มีไอคอนธีม) บรรทัดล่าง **โรงพยาบาลสันทราย** (มีกากบาทเล็ก) แถบสีด้านซ้าย = สีของระบบ
(ภายในระบบ ป้ายของห้องหน้าเว็บเขียน `ชื่อระบบ · โรงพยาบาลสันทราย`) · ชื่อยาวย่อขนาดตัวอักษรให้พอดี · ชี้เมาส์/แตะ = ขอบสว่าง · ระบบที่หยุดเก็บ/ยังไม่มีข้อมูล = ป้ายจางลง
ชื่อโรงพยาบาลอยู่ที่เดียว: `HOSPITAL_NAME` ใน site-deco.js

## ตัวคน

ตัวคนทุกคน (ผู้เข้าใช้ในผัง · คนบนถนน/ในตึกของ รพ.) มี หัว คอ ลำตัว แขน 2 ข้าง ขา 2 ข้าง ผม รองเท้า และใบหน้า (จอใหญ่/ซูมเข้า) · เดินแล้วแกว่งแขนขาและตัวขึ้นลง · ยืนทำงานแขนห้อย/ถือของ
รูปร่าง ผิว ทรงผม (ผมสั้น/ผมยาว กระโปรง/กางเกง) ต่างกันตามรหัสผู้เข้าชม — คนเดิมหน้าตาเดิมทุกเฟรม · คนที่กลับมาซ้ำวันเดียวกันยังมีวงแหวนทอง/เส้นขอบเหมือนเดิม

| บทบาท | ชุด / ของในมือ | จุดสีเหนือหัว (legend เดิม) |
|---|---|---|
| ผู้ดูแลระบบ (แอดมิน) | สูทม่วง เนกไท แว่นตา | ม่วง |
| หัวหน้างาน | สูทส้ม ผมสีเทา ถือคลิปบอร์ด | ส้ม |
| เจ้าหน้าที่ | เสื้อฟ้าอมเขียว สายคล้อง + บัตร | ฟ้าอมเขียว |
| กรรมการ | แจ็กเก็ตเขียว ถือเอกสาร | เขียว |
| ผู้วิจัย | เสื้อกาวน์ขาว ปกชมพู แว่นตา หลอดทดลอง | ชมพู |
| ผู้ใช้ทั่วไป | เสื้อเทา สะพายเป้ ถือมือถือ | เทา |
| (ไม่ทราบบทบาท) | เสื้อสีของห้อง | – |

คนบนถนน/ในตึก: แพทย์ (เสื้อกาวน์ + หูฟังตรวจ) · พยาบาล (ชุดฟ้าอมเขียว + หมวก) · ผู้ป่วย (ชุดสีฟ้า) · คนงาน (หมวกนิรภัย + เสื้อสะท้อนแสง) · ผู้มาติดต่อ (สีสุ่ม บางคนสะพายเป้) · เด็ก
ไม่มีการอ่านหรือแสดงชื่อ/รหัสของบุคคลจริง — รหัสใช้เลือกผม/ผิว/ทรงเท่านั้น

## ไฟล์ที่ต้องวางทับ

```
src/js/modules/site-deco.js     (ใหม่)   ตัวเลขลอย · ป้ายฐาน · ตัวคน
src/js/modules/site-sim.js      (แก้)    ต่อเข้า 3 มุมมอง + โมเดล eval + ตัวคนใหม่
src/js/modules/site-engine.js   (แก้)    ธีม eval + กฎจับชื่อ + ปีกพัฒนาคุณภาพ
src/js/modules/dashboard.js     (แก้)    ข้อความแจ้งไฟล์ที่ต้องอัปโหลดครบ (เพิ่ม site-deco.js)
tests/unit/site-deco.test.mjs   (ใหม่)
```
ถ้าหน้าแรกเป็นหน้าว่างหลังอัปโหลด ให้เช็กว่าอัปโหลด `site-deco.js` แล้ว (แคชเก่าจะล้างตัวเองหนึ่งครั้ง)
