# หน้าแรก 3 มิติ: โมเดลของแต่ละระบบ · ป้ายฐาน · ตัวคน · ตัวดู 3D หมุนได้

หน้าแรกมี 2 แบบให้สลับด้วยปุ่ม **🧊 3D หมุนได้** (ข้างแท็บผังแผนก/โรงพยาบาล) — ใช้ข้อมูลชุดเดียวกัน (ระบบ · สถานะ · ตัวเลข · ผู้เข้าใช้ · บทบาท)

| | ภาพแบน (isometric เดิม) | **3D หมุนได้** (ใหม่) |
|---|---|---|
| เทคนิค | canvas 2D เขียนเอง | WebGL (three.js) โหลดเมื่อกดปุ่มเท่านั้น |
| มุมมอง | คงที่ ลากเลื่อนซูมได้ | หมุนรอบ · เลื่อน · ซูม · มุมบน · หมุนเอง |
| เหมาะกับ | จอใหญ่ ดูภาพรวมทั้งผัง/ทางเดินของคน/เข้าไปดูภายในระบบ | มือถือ จอสัมผัส ดูโมเดลชัด ๆ รอบด้าน |
| การทับกัน | ตัวจัดวางป้ายเลี่ยงการทับ (เลือกที่ทับน้อยสุด) | วางผังเป็นตาราง ไม่มีโมเดลทับกัน |

บนจอกว้าง ≤ 700px ครั้งแรกจะเปิด 3D ให้เอง (ถ้าอุปกรณ์รองรับ WebGL) — กลับภาพแบนด้วยปุ่ม "◻ กลับภาพแบน" ระบบจำสิ่งที่เลือก (`sand:home3d:render`) · ไม่รองรับ WebGL → ใช้ภาพแบนต่อ

## ไม่มีตัวหนังสือลอย

* **ป้ายฐาน** ตั้งอยู่บนพื้นตรงฐานโมเดล: ชื่อระบบ · **ตัวเลขการใช้งาน (นูน 3 มิติ นับขึ้นเมื่อค่าเปลี่ยน)** · `ครั้ง` · `● ออนไลน์ N` · **โรงพยาบาลสันทราย** (มีกากบาท) · แถบสีของระบบ — ระบบที่ไม่มีข้อมูล/เงียบ/หยุดเก็บ แสดงคำสถานะแทนตัวเลข
* ภาพแบน: ป้ายขยับหลบเมื่อจะทับโมเดลอื่น (มี **วงแหวนรอยเท้า** ที่ฐานโมเดล และเส้นนำสีเดียวกันโยงถึงป้าย) · ป้ายอื่นทั้งหมดเป็นป้ายปักเสามีเงาบนพื้น · ป้ายซ้อนกันจะถูกจัดแยก ป้ายที่ไม่สำคัญและหาที่ไม่ได้จะถูกซ่อน (ไม่รกบนจอเล็ก) · ชื่อหน้าย่อยในแผนกแสดงเมื่อชี้/แตะ
* 3D: ชื่อ/ตัวเลข/โรงพยาบาลพิมพ์บน **แท่นป้าย** ที่พื้นหน้าโมเดล ทั้ง 4 ด้าน (อ่านได้ทุกมุมที่หมุน)
* ชื่อโรงพยาบาลอยู่ที่เดียว: `HOSPITAL_NAME` ใน site-deco.js

## วิธีใช้ 3D หมุนได้

| ทำ | มือถือ | คอมพิวเตอร์ |
|---|---|---|
| หมุน | ลากนิ้วเดียว | ลากเมาส์ · ลูกศรซ้าย/ขวา/ขึ้น/ลง |
| ซูม | บีบสองนิ้ว | ล้อเมาส์ · `+` `−` |
| เลื่อน | ลากสองนิ้ว | คลิกขวาลาก |
| ดูระบบหนึ่ง | แตะระบบ หรือแตะชื่อในแถบด้านล่าง | คลิกระบบ หรือคลิกชื่อในแถบ |
| กลับภาพรวม | ปุ่ม ↺ หรือ ✕ | ปุ่ม ↺ · Esc |

การ์ดรายละเอียดมีปุ่ม **ดูรายละเอียดโครงการ** (เปิดหน้ารายละเอียดเดิม) และ **เข้าไปดูภายในระบบ** (ภาพแบนมุมมองภายในระบบเดิม) · ปุ่มทุกปุ่มสูง ≥ 44px · แถบรายชื่อระบบเป็นปุ่มจริง (ใช้กับโปรแกรมอ่านหน้าจอได้)

ประสิทธิภาพ: ใช้ 142 draw call · ชิ้นที่ไม่ขยับรวมเป็นก้อนเดียวต่อกลุ่ม (สีต่อจุดยอด) · ไม่ใช้เงาแบบเรียลไทม์ (ใช้เงาจุดแทน) · pixel ratio ≤ 1.75 บนจอสัมผัส · 40 fps บนจอสัมผัส · หยุดวาดเมื่อซ่อน/เลื่อนพ้นจอ · ลดการเคลื่อนไหวในเครื่อง = ภาพนิ่ง ไม่เดิน ไม่นับขึ้น

## โมเดลประจำระบบ (ทั้ง 2D และ 3D)

| ระบบ | ธีม | โมเดล | จับอัตโนมัติจาก |
|---|---|---|---|
| ระบบยานพาหนะ SAND | `ems` 🚑 | รถพยาบาล · ไฟหลังคาแดง/น้ำเงินสลับกะพริบเมื่อมีคนออนไลน์ | ยานพาหนะ · รถ · sand · ems |
| HRD | `hrd` 🎓 | ห้องอบรม: กระดานขาว แท่นวิทยากร โต๊ะเรียน 3×2 + เก้าอี้ | hrd · อบรม · บุคลากร |
| ยื่นจริยธรรมการวิจัยในมนุษย์ | `ec` 🔬 | โต๊ะแล็บ กล้องจุลทรรศน์ ขวดทดลอง เอกสาร + **โล่จริยธรรม** | จริยธรรม · วิจัย · ec · irb |
| วัคซีน | `vaccine` 💉 | ตู้เย็นวัคซีน กล่องเย็น ขวดวัคซีน + **เข็มฉีดยาขนาดใหญ่** | วัคซีน · vaccine · epi |
| **ติดตามประเมินผลงาน / ยื่น อวช.** *(ใหม่)* | `eval` 🏆 | ผนังความคืบหน้า 4 ขั้น+เครื่องหมายถูก → ถาดแฟ้มที่ยื่น → โต๊ะตรวจ+จอ → แท่นรับรางวัล 3 ขั้น + **ถ้วยหมุน** | อวช · ประเมินผลงาน · ติดตามผลงาน · ยื่นผลงาน · portfolio |
| (อื่น ๆ) | `plan` `dental` `pt` `doc` `visit` `fte` `web` | กระดาน KPI · เก้าอี้ทันตกรรม · เตียง+ราวกายภาพ · ตู้เอกสาร · บ้าน+หมุด · แผนผังองค์กร · จอ+ตู้เซิร์ฟเวอร์ | ตามเดิม |

* บังคับธีมด้วยแท็กในโครงการ: `theme:eval` `theme:ems` `theme:hrd` `theme:ec` `theme:vaccine` ฯลฯ
* ระบบ `eval` อยู่ปีก "พัฒนาคุณภาพ" ของตึกผู้ป่วยนอก (เปลี่ยนด้วยแท็ก `group:…` / `bld:…` เหมือนเดิม)
* "อวช." ผมตีความเป็นปลายทางของการยื่นผลงานเพื่อรับการประเมิน — ถ้าความหมายต่างไป แก้เฉพาะกฎคำค้นใน `RULES` (site-engine.js) หรือใช้แท็ก `theme:eval`
* โมเดลเป็นโค้ด ไม่ใช่ไฟล์ glTF (ระบบเดิมไม่ใช้ไฟล์โมเดล) · เพิ่มระบบใหม่: ธีมใน `THEMES` + กฎใน `RULES` (site-engine.js) · ภาพแบน `else if (th === '…')` ใน `prop()` (site-sim.js) · 3D ฟังก์ชันใน `MODELS` (site-models3d.js) · ใส่ธีมในปีกของ `HOSP_GROUPS`
* โมเดล 3D แต่ละชิ้นอยู่ในพื้นที่ ≤ 3.8 กว้าง × 2.7 สูง กลางแท่นเสมอ (มีเทสต์ตรวจ) เว้นทางเดินและแท่นป้ายด้านหน้าให้โล่ง

## ตัวคน

หัว คอ ลำตัว แขน 2 ข้าง ขา 2 ข้าง ผม รองเท้า (ภาพแบนมีใบหน้า/แว่นตาเมื่อซูมเข้า) · เดินแล้วแกว่งแขนขา · รูปร่าง ผิว ทรงผม กางเกง/กระโปรง ต่างกันตามรหัสผู้เข้าชม (คนเดิมหน้าตาเดิม) · ใน 3D คนที่เดินเป็น 1 ใน 3 ส่วนที่เหลือยืนข้างแท่นป้าย (ไม่บังป้าย) และเดินตามทางเดินรอบหลังแท่น ไม่เดินทะลุโมเดลหรือแท่นป้าย

| บทบาท | ชุด / ของในมือ | จุดสีเหนือหัว (ภาพแบน) |
|---|---|---|
| ผู้ดูแลระบบ (แอดมิน) | สูทม่วง เนกไท แว่นตา | ม่วง |
| หัวหน้างาน | สูทส้ม ผมสีเทา คลิปบอร์ด | ส้ม |
| เจ้าหน้าที่ | เสื้อฟ้าอมเขียว สายคล้อง + บัตร | ฟ้าอมเขียว |
| กรรมการ | แจ็กเก็ตเขียว ถือเอกสาร | เขียว |
| ผู้วิจัย | เสื้อกาวน์ขาว ปกชมพู แว่นตา หลอดทดลอง | ชมพู |
| ผู้ใช้ทั่วไป | เสื้อเทา สะพายเป้ ถือมือถือ | เทา |

คนบนถนน/ในตึก (ภาพแบน): แพทย์ (เสื้อกาวน์ + หูฟังตรวจ) · พยาบาล (ชุดฟ้าอมเขียว + หมวก) · ผู้ป่วย · คนงาน (หมวกนิรภัย + เสื้อสะท้อนแสง) · ผู้มาติดต่อ · เด็ก
ไม่มีการอ่านหรือแสดงชื่อ/รหัสของบุคคลจริง — รหัสใช้เลือกผม/ผิว/ทรงเท่านั้น

## ไฟล์ที่ต้องวางทับ

```
src/js/modules/site-deco.js        (ใหม่)  ป้ายฐาน · ป้ายปักเสา · ตัวจัดวาง · ตัวคนภาพแบน
src/js/modules/site-3d.js          (ใหม่)  ตัวดู 3D (กล้อง การแตะ การ์ด แถบรายชื่อ)
src/js/modules/site-models3d.js    (ใหม่)  โมเดล 3D ทุกระบบ + ตัวคน 3D + ตัวรวมชิ้นส่วน
src/js/vendor/three/               (ใหม่)  three.module.min.js · OrbitControls.js · LICENSE (three.js r160, MIT)
src/js/modules/site-sim.js         (แก้)
src/js/modules/site-engine.js      (แก้)   ธีม eval
src/js/modules/dashboard.js        (แก้)   ข้อความแจ้งไฟล์ที่ต้องอัปโหลด
src/css/site3d.css                 (แก้)
src/sw.js                          (แก้)   แคช three เมื่อใช้ครั้งแรก (ไม่ precache)
scripts/build.mjs                  (แก้)   ไม่ precache src/js/vendor/three/
tests/unit/site-deco.test.mjs · tests/unit/site-models3d.test.mjs   (ใหม่)
```
ถ้าหน้าแรกว่างหลังอัปโหลด ให้เช็กว่าอัปโหลดครบ (โดยเฉพาะ `site-deco.js`) · ถ้าปุ่ม 3D ขึ้นว่าเปิดไม่ได้ ให้เช็กว่าอัปโหลดโฟลเดอร์ `src/js/vendor/three/` (บางตัวอัปโหลดข้ามโฟลเดอร์ vendor) และเบราว์เซอร์/เครื่องเปิด WebGL
