# หนังสือรับเข้า (ธุรการ) จาก Telegram — คู่มือติดตั้ง

ระบบ **ฟังเงียบ ๆ** ในกลุ่ม Telegram แล้วนำหนังสือเวียน (ลิงก์ / ไฟล์ PDF / ข้อความ) มาเป็น “ร่างหนังสือรับเข้า” ให้ธุรการตรวจและกดรับ
บอท **ไม่ส่งข้อความ ไม่ตอบ ไม่กดรีแอ็กชัน** ในกลุ่มเลย (ไม่มีโค้ดส่งข้อความอยู่ในระบบ และ `tests/inbox.test.mjs` ตรวจเรื่องนี้ทุกครั้ง)

```
กลุ่ม Telegram → /api/telegram (Vercel) → Apps Script (action "tg") → แท็บ Inbox + Drive
                                                                    → หน้าเว็บ “หนังสือรับเข้า” → ธุรการตรวจ → รับหนังสือ → เลขรับ n/ปี พ.ศ.
```

## 1) สร้างบอท (ทำครั้งเดียว)
1. คุยกับ **@BotFather** → `/newbot` → เก็บ token ไว้ (อย่าโพสต์ที่ไหน)
2. `/setprivacy` → เลือกบอท → **Disable** (ให้บอทเห็นข้อความในกลุ่ม ไม่ใช่เฉพาะคำสั่ง)
3. `/setjoingroups` → **Disable** หลังเพิ่มบอทเข้ากลุ่มของคุณแล้ว (กันคนอื่นลากบอทไปกลุ่มอื่น)
4. เพิ่มบอทเข้ากลุ่ม (ในฐานะสมาชิกธรรมดาก็พอ — ถ้าเป็น *ช่อง* ต้องตั้งเป็นแอดมิน) แล้วตั้งการแจ้งเตือนของบอทเป็นปิดเสียง ไม่จำเป็นต้องให้สิทธิ์ส่งข้อความ
   - จะ **ถอนสิทธิ์ส่งข้อความของบอท** ในกลุ่มด้วยก็ได้ เพื่อให้แน่ใจ 100% ว่าส่งไม่ได้ (Group info → Permissions)

## 2) หา chat id ของกลุ่ม
ให้ใครสักคนพิมพ์ในกลุ่ม 1 ข้อความ แล้วรัน (ก่อนตั้ง webhook):
```
TG_BOT_TOKEN=123:abc node scripts/telegram-webhook.mjs chats
```
จะได้เลขแบบ `-1001234567890`

## 3) Apps Script
1. เพิ่มไฟล์ `gas/Inbox.gs` และวาง `gas/Code.gs` ฉบับใหม่ (มี action `inbox` และ `tg`)
2. รัน `setupInbox` หนึ่งครั้ง (สร้างแท็บ Inbox)
3. Project Settings → Script properties:

| ชื่อ | ค่า |
|---|---|
| `TG_ALLOWED_CHATS` | chat id ของกลุ่ม (หลายกลุ่มคั่นด้วย `,`) — **ว่าง = ไม่รับอะไรเลย** |
| `TG_BOT_TOKEN` | token ของบอท (ใช้แค่คัดลอกไฟล์ PDF ลง Drive; เว้นว่างได้ ระบบยังเก็บข้อความ/ลิงก์) |
| `INBOX_STAFF_EMAILS` | อีเมลเจ้าหน้าที่ธุรการ (ผู้ดูแลใน `ADMIN_EMAILS` ใช้ได้อยู่แล้ว) |
| `TG_KEYWORDS` | (ไม่บังคับ) คำที่ใช้ตัดสินว่าเป็นหนังสือ คั่นด้วย `,` ค่าเริ่มต้น: หนังสือเวียน, หนังสือ, ที่ ศธ, ลงวันที่, เรื่อง, ขอเชิญ ฯลฯ |
| `TG_CAPTURE_ALL` | (ไม่บังคับ) `true` = เก็บทุกข้อความที่มีลิงก์/ไฟล์จากกลุ่มที่อนุญาต |

4. **Deploy → Manage deployments → Edit → New version** (ต้อง Authorize ใหม่ถ้าระบบถาม)
5. ถ้ายังไม่เคยรัน `setupLinks` ให้รันก่อน เพื่อให้มี `EDGE_SECRET`

## 4) Vercel
Environment Variables (เพิ่มจากที่มีอยู่ `SAND_GAS_URL`, `SAND_EDGE_SECRET`):

| ชื่อ | ค่า |
|---|---|
| `SAND_TG_WEBHOOK_SECRET` | สตริงสุ่มยาว ≥ 16 ตัว (A-Z a-z 0-9 _ -) เช่น `openssl rand -hex 24` |
| `SAND_TG_CHATS` | chat id เดียวกับ `TG_ALLOWED_CHATS` |

แล้ว Redeploy จากนั้นตั้ง webhook:
```
TG_BOT_TOKEN=123:abc SAND_TG_WEBHOOK_SECRET=ค่าเดียวกับใน Vercel \
  node scripts/telegram-webhook.mjs set https://โดเมนของคุณ/api/telegram
node scripts/telegram-webhook.mjs info     # pending ควรเป็น 0 และไม่มี lastError
```

## 5) ใช้งาน
เมนู **หนังสือรับเข้า** (เฉพาะธุรการ/ผู้ดูแล): รายการ “รอตรวจ” → เปิดดู แก้เรื่อง/เลขที่/วันที่/หน่วยงาน → **รับหนังสือ (ออกเลขรับ)**
- เลขรับรันต่อเนื่องตามปี พ.ศ. (`1/2569`, `2/2569`, …) ครั้งแรกกรอกเลขเองได้ (เช่น `150`) ให้ต่อจากทะเบียนเล่มเดิม
- หนังสือที่รับแล้วจะถูกล็อกเลขรับ (ไม่ลบ/ไม่ใช้เลขซ้ำ) แก้ข้อมูลอื่นได้
- **นำเข้าย้อนหลัง**: Telegram Desktop → เปิดกลุ่ม → ⋮ → Export chat history → รูปแบบ JSON → เลือก `result.json` (บอทดึงข้อความเก่าเองไม่ได้)
- ข้อความ/ลิงก์ซ้ำ (ข้อความเดิม หรือลิงก์เดียวกันโพสต์อีกครั้ง) จะไม่ถูกเก็บซ้ำ

## ความเป็นส่วนตัว / ความปลอดภัย
- รับเฉพาะกลุ่มใน allow-list (ตรวจทั้งที่ Vercel และ Apps Script) และเฉพาะข้อความที่มีลิงก์/ไฟล์และเข้าข่ายหนังสือ
- ไม่เก็บชื่อผู้ส่ง รูปโปรไฟล์ หรือเบอร์โทร — เก็บแค่ข้อความ ลิงก์ ชื่อกลุ่ม และเวลา
- webhook ตรวจ secret header ของ Telegram; Apps Script รับเฉพาะคำขอที่มี `EDGE_SECRET`
- ไฟล์ PDF เก็บที่ `<DRIVE_FOLDER_ID>/<yyyy-MM>/_inbox/` และแชร์แบบอ่านอย่างเดียวให้ธุรการ/ผู้ดูแล (จำกัด 10 MB)
- ข้อความในแชทไม่น่าเชื่อถือ: ระบบไม่ออกเลขรับให้เอง และเปิดลิงก์ด้วยปุ่มที่ธุรการกดเองเท่านั้น

## แก้ปัญหา
- ไม่มีอะไรเข้ามา: `info` ดู `lastError`; ตรวจว่าปิด Privacy Mode *หลัง* เพิ่มบอทแล้ว (ถ้าเปิดทีหลังให้เอาบอทออกแล้วเพิ่มใหม่), chat id ตรงกันทั้งสองที่, ข้อความมีลิงก์/ไฟล์และคำสำคัญ
- ไฟล์ PDF ไม่ถูกคัดลอก: ตั้ง `TG_BOT_TOKEN` หรือไฟล์ใหญ่เกิน 10 MB (ยังเก็บข้อความ/ลิงก์ไว้)
- ธุรการเปิดหน้าแล้วขึ้น “ไม่มีสิทธิ์”: เพิ่มอีเมลใน `INBOX_STAFF_EMAILS`
