## โมเดลประจำระบบ (ตรวจอัตโนมัติจากชื่อ/ที่อยู่เว็บ/แท็กของโครงการ)
SAND/ยานพาหนะ/รถ → รถพยาบาล (ไฟฉุกเฉินกะพริบเมื่อมีคนออนไลน์) · HRD/อบรม → ห้องอบรม · EC/จริยธรรม/วิจัย → ห้องวิจัย + โล่
วัคซีน → ห้องวัคซีน · ทันตกรรม → เก้าอี้ทันตกรรม · กายภาพ → เตียง+บาร์ · แผนงาน/KPI → บอร์ด Gantt · สารบรรณ → ตู้เอกสาร · เยี่ยมบ้าน/แผนที่ → บ้าน+หมุด · อื่นๆ → โต๊ะ+จอ
บังคับเองได้: ใส่แท็กในโครงการเป็น `theme:ems` `theme:hrd` `theme:ec` `theme:vaccine` `theme:dental` `theme:pt` `theme:plan` `theme:doc` `theme:visit` `theme:web`
(เพิ่มกฎคำค้นเองได้ที่ RULES ใน site-engine.js · "SAND Office Tools" จะไม่ถูกนับเป็นรถ)


## มุมมอง "ภายในระบบ" (ใหม่)
คลิกสถานี (หรือปุ่ม "เข้าไปดูภายใน ›" ในตาราง) → กล้องซูมเข้าไปในระบบ แต่ละ **หน้าของเว็บ = 1 ห้อง 3 มิติ** · คนเดินจากห้องหนึ่งไปอีกห้องตามที่ผู้ใช้เปลี่ยนหน้าจริง
เส้นบนทางเดิน = จำนวนคนที่ไปจากหน้า A → B (ตัวเลขบนเส้น) · คลิกห้อง = ซูมเข้า + การ์ดรายละเอียด (มาจากหน้าไหน/ไปต่อที่ไหน) · Esc = ถอยกลับ
ข้อมูล: GAS `projects` op `pages` (ใช้ Analytics.gs ใหม่) · ถ้ายังเป็น Analytics.gs เก่า จะใช้ `stats` แทน (ได้ตัวเลขรายหน้า แต่ไม่มีเส้นทางเดิน และมีแถบเตือน)

| ชนิดหน้า (เดาจากชื่อไฟล์) | โมเดล | ตัวอย่าง |
|---|---|---|
| หน้าแรก/โฟลเดอร์ระบบ | เคาน์เตอร์ต้อนรับ+ป้าย | /carsystemsansai , index.html |
| เลขไมล์ | มาตรวัด+รถ | startmile, editmile |
| ตรวจสภาพรถ | รถ+เช็คลิสต์ที่ติ๊กทีละข้อ | check |
| ตรวจรถ EMS | รถพยาบาล+เช็คลิสต์ | EMScheck |
| ตารางงาน | ปฏิทินบนผนัง+โต๊ะ | worktable |
| แดชบอร์ด | จอกราฟเคลื่อนไหว | dashboard |
| สลับ/แลกเปลี่ยน | สองโต๊ะ+โทเคนวิ่งไป-มา | swap |
| แผนที่ | โต๊ะแผนที่+เส้นทาง+หมุด | routemap |
| รายงาน / ผู้ดูแล / แบบฟอร์ม / เข้าสู่ระบบ / อื่นๆ | เครื่องพิมพ์ / ตู้เซิร์ฟเวอร์ / ฟอร์ม / ประตูกั้น / กล่องแฟ้ม | |

เพิ่มชนิดหน้าใหม่: `PAGE_KINDS` + `PAGE_RULES` (site-engine.js) → สี `PAGE_COL` + `case` ใน `drawRoom()` (site-rooms.js) · ตั้งชื่อไทยของหน้าที่ `PAGE_LABELS`
แสดงสูงสุด 10 ห้องต่อระบบ (`MAX_PAGES`) ที่เหลือรวมเป็นห้อง "หน้าอื่นๆ"
